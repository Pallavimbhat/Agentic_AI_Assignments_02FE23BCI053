## Running the Assignments

1. Clone the repository:

   ```bash
   git clone https://github.com/Pallavimbhat/Agentic_AI_Assignments_02FE23BCI053.git
   ```

2. Navigate to the required lab folder:

   ```bash
   cd Agentic_AI_Assignments_02FE23BCI053
   ```

3. Execute the required Python assignment:

   ```bash
   python Lab5_Assignment1.py
   ```

   Replace the filename with the assignment you want to execute.
